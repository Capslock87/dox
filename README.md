# Green Crops — Интерактивная карта с базой данных MySQL

Проект веб-сайта агропромышленной компании **Green Crops** с интерактивной картой Google Maps и хранением объектов (офисы, поля, границы-полигоны) в реляционной базе данных **MySQL**.

---

## 📁 Структура файлов проекта

| Файл | Описание |
|------|----------|
| `database.sql` | Полный SQL-скрипт создания базы данных `green_crops_db`, таблицы `locations` и заполнения всеми 14 объектами (2 офиса и 12 полей с полигонами). |
| `add_10_fields.sql` | Скрипт быстрой миграции: вставляет 10 новых полей в районе Kucice без удаления существующих данных. |
| `server.js` | Бэкенд-сервер на Node.js (Express + `mysql2`) с REST API и раздачей фронтенда. |
| `package.json` | Манифест зависимостей (`express`, `mysql2`, `cors`, `dotenv`). |
| `.env` / `.env.example` | Файл настроек подключения к MySQL (хост, порт, пользователь, пароль, имя БД). |
| `index.html` | Адаптивная страница с сайдбаром, картой и модальным окном каталога салатов. |
| `styles.css` | Стили интерфейса (премиум dark-emerald тема, карточки салатов, адаптивность). |
| `app.js` | Логика фронтенда: загрузка данных через REST API, fallback-режим, каталог салатов, полигоны. |

## 🚀 Быстрый старт: Пошаговая инструкция

### Шаг 1. Импорт или обновление базы данных в MySQL

Вы можете выбрать один из двух вариантов:

#### Вариант 1 (Если база уже создана ранее): Добавить только 10 новых полей
Выполните скрипт **`add_10_fields.sql`**:
- **phpMyAdmin**: вкладка «Импорт» ➔ выберите `add_10_fields.sql` ➔ «Вперёд».
- **Workbench / DBeaver**: откройте `add_10_fields.sql` и нажмите **Execute**.
- **Консоль**:
  ```powershell
  mysql -u root -p green_crops_db < add_10_fields.sql
  ```

#### Вариант 2 (С чистого листа): Импортировать полную базу
Выполните скрипт **`database.sql`** (содержит всё: создание БД + все 14 объектов):
```powershell
mysql -u root -p < database.sql
```


---

### Шаг 2. Настройка подключения к БД (.env)

Откройте файл `.env` в корне проекта и при необходимости укажите ваши параметры подключения:

```env
PORT=3000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=ваш_пароль_если_есть
DB_NAME=green_crops_db
```

---

### Шаг 3. Установка зависимостей и запуск сервера

В папке проекта выполните в терминале:

1. Установка пакетов:
   ```powershell
   npm install
   ```

2. Запуск сервера:
   ```powershell
   npm start
   ```
   *(для режима автоперезапуска при изменениях используйте `npm run dev`)*

3. В консоли появится сообщение:
   ```text
   🌱 ================================================
   🚀 Сервер Green Crops запущен на: http://localhost:3000
   📡 REST API доступен по: http://localhost:3000/api/locations
   🌱 ================================================
   ✅ Успешное подключение к базе данных MySQL (green_crops_db) на localhost:3306
   ```

4. Откройте в браузере:
   👉 **http://localhost:3000**

## 🛡️ Отказоустойчивость (Fallback-режим)

Сайт разработан максимально надежным:
- Если сервер MySQL или Node.js запущен — данные **автоматически считываются в реальном времени из базы данных**.
- Если сервер MySQL временно выключен или сайт открыт прямо файлом `index.html` в браузере — сайт **не выдает ошибок**, а плавно переключается на встроенные резервные данные.

## 📡 REST API Эндпоинты

Бэкенд предоставляет удобное REST API для интеграции:

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/health` | Проверка статуса сервера и соединения с MySQL |
| `GET` | `/api/locations` | Получение всех активных объектов (поддерживает `?type=office` или `?type=field`) |
| `GET` | `/api/locations/:id` | Получение одного объекта по ID |
| `POST` | `/api/locations` | Создание нового объекта (офиса или поля) |
| `PUT` | `/api/locations/:id` | Редактирование существующего объекта |
| `DELETE`| `/api/locations/:id` | Деактивация объекта (мягкое удаление) |

### Пример тела запроса при добавлении поля (POST `/api/locations`):
```json
{
  "type": "field",
  "name": "Новое поле Мазовецкое C-01",
  "lat": 52.4500,
  "lng": 21.1500,
  "area": 95.5,
  "crop": "Кукуруза (Corn)",
  "description": "Новый полигон для органического земледелия.",
  "polygon": [
    { "lat": 52.4550, "lng": 21.1400 },
    { "lat": 52.4560, "lng": 21.1600 },
    { "lat": 52.4450, "lng": 21.1580 },
    { "lat": 52.4440, "lng": 21.1390 }
  ]
}
```

## 🥗 Каталог салатов и культур Green Crops

В интерфейс добавлено интерактивное окно со всеми 12 культурами компании:
- **Кнопка вызова**: доступна в шапке сайдбара («Каталог салатов (12 сортов)») и в верхнем правом углу карты.
- **Поиск и категории**: фильтрация по категориям (Кочанные, Листовые, Цикорные, Baby-leaf) и поиск по вкусу или названию.
- **Интеграция с картой**: у каждого салата есть кнопка **«На поле на карте»**, которая мгновенно закрывает каталог, плавно перемещает карту на соответствующее поле, приближает масштаб и открывает всплывающую карточку с границами-полигоном.
